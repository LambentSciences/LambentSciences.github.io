03 — Process

Concept to prototype

Six stages, each with a clear output, so every program can be planned, funded and tracked.

Discuss a program

  1. Stage 01

    Concept

    Define the problem and the laser approach worth pursuing.

  2. Stage 02

    Feasibility

    Model, estimate, and identify the main technical risks.

  3. Stage 03

    Design

    Specify optics, source, controls, and safety requirements.

  4. Stage 04

    Build

    Assemble and integrate the prototype with qualified suppliers.

  5. Stage 05

    Test

    Measure performance against the agreed targets.

  6. Stage 06

    Handoff

    Deliver data, documentation, and recommended next steps.
